# Портфоліо Максима Кулика

Статична адаптивна сторінка портфоліо, розміщена в окремій папці, щоб не перезаписувати головну сторінку інших проєктів у репозиторії.

## Перегляд

Після публікації GitHub Pages сторінка доступна за адресою:
https://omeljanpadovcky-create.github.io/T/maxym-kulyk-portfolio/

## Що потрібно персоналізувати

- Додати перевірену біографію та професійний напрямок Максима.
- Замінити три шаблонні картки на справжні проєкти та посилання.
- Додати актуальну електронну пошту чи соціальні мережі.
- Замінити тимчасові навички на підтверджені.

Сторінка не вигадує досвід або контактні дані: відповідні місця явно залишені для заповнення.
