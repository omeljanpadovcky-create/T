# 🐭 Crypto Myshka — локальний аналіз скріншотів JEV

Це **локальна** функція для аналізу зображення графіка. Вона не відкриває угод, не копіює ставки, не надсилає фото в Telegram чи хмарний AI. Дані зображення передаються лише між браузером, локальним Python-сервером і локальною Ollama.

## Перший запуск у Windows PowerShell

1. Встанови [Ollama для Windows](https://ollama.com/download/windows) та [Python 3.10+](https://www.python.org/downloads/windows/) (під час інсталяції Python увімкни **Add python.exe to PATH**, якщо доступно).
2. Відкрий PowerShell і введи:

```powershell
cd C:\Users\lolsi\T
git pull
powershell -NoProfile -ExecutionPolicy Bypass -File .\START_MYSHKA_AI.ps1
```

3. Якщо скрипт запитає `Download the vision model now? (Y/N)`, введи **Y**. Завантаження моделі `qwen2.5vl:3b` може зайняти кілька гігабайтів. На слабкій відеокарті перший аналіз може тривати довго або виконуватися на CPU.
4. Дочекайся відкриття **http://127.0.0.1:18765/myshka-app.html#analysis**. **Не відкривай GitHub Pages** для локального аналізу.
5. Перевір зелений статус **JEV готовий**, натисни **Обрати фото графіка** або **Win+Shift+S → Ctrl+V**. Після обробки з'явиться **↑ ВГОРУ**, **↓ ВНИЗ** або **— НЕВИЗНАЧЕНО**.

## Якщо щось не працює

У **другому** вікні PowerShell перевір:

```powershell
ollama list
Invoke-RestMethod http://127.0.0.1:11434/api/tags
Invoke-RestMethod http://127.0.0.1:18765/api/chart-health
```

- **404 File not found**: відкрито не той сервер або порт. Закрий старі локальні сервери, запусти `START_MYSHKA_AI.ps1` і відкрий **порт 18765**.
- **Ollama не відповідає**: запусти Ollama або виконай `ollama serve` в іншому PowerShell.
- **Модель відсутня**: виконай `ollama pull qwen2.5vl:3b` і повтори аналіз.
- **Стара сторінка**: зроби `git pull`, перезапусти локальний сервер і натисни **Ctrl+F5** у браузері.
- **Порт 18765 зайнятий**: закрий старе вікно Мишки (`Ctrl+C`) або перевір процес: `Get-NetTCPConnection -LocalPort 18765 -ErrorAction SilentlyContinue`.
- **Python не знайдено**: встанови Python, закрий та відкрий PowerShell.
- **Довго думає**: перший запуск моделі потребує часу та оперативної пам'яті; не закривай PowerShell, поки триває запит.

Для завершення роботи натисни **Ctrl+C** у PowerShell, де працює сервер.

## Що саме визначає JEV

JEV бачить лише завантажений скріншот, а не майбутні свічки або незалежно перевірені котирування. Результат — оцінка **видимого** короткострокового руху, а не сигнал для реальної ставки. Якщо зображення нечітке або рух змішаний, відповідь має бути **НЕВИЗНАЧЕНО**.

Інші розділи Crypto Myshka (LIVE, історія, налаштування, Telegram) не залежать від цього локального модуля.
