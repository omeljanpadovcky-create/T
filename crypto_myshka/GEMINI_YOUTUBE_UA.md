# 🐭 ТрейдМишка: Gemini аналізує YouTube-ролики

## Що саме відбувається

Архів у додатку myshka-app.html#archive збирає доступні публічні YouTube-ролики, Shorts і записи ефірів. Старі відео залишаються, нові додаються за video ID. Обхід YouTube запланований раз на 2 години; доступ YouTube і GitHub Actions може бути обмежений, повне охоплення всього каталогу не гарантується.

**Основний шлях:** пряме публічне YouTube-посилання → офіційний Gemini Video Understanding API → Gemini бачить кадри й звук без субтитрів → конспект, пари, індикатори, стратегія, часові мітки → картка в архіві. Відеофайли не копіюємо.

**Запасний шлях:** якщо API недоступний, залишаються назви, описи й іноді субтитри. JEV може зробити текстовий конспект лише з доступного тексту. Картка відрізняє Gemini-відеоаналіз від субтитрів і просто метаданих.

## Увімкнення Gemini

1. Отримайте власний Gemini API-ключ: https://aistudio.google.com/apikey
2. Відкрийте GitHub Actions Secrets: https://github.com/omeljanpadovcky-create/T/settings/secrets/actions
3. Натисніть New repository secret, назвіть секрет GEMINI_API_KEY та вставте ключ Google AI Studio.
4. Відкрийте https://github.com/omeljanpadovcky-create/T/actions/workflows/crypto-myshka-video-archive.yml і натисніть Run workflow або дочекайтеся запуску за графіком.
5. Відкрийте https://omeljanpadovcky-create.github.io/T/myshka-app.html#archive — Gemini-звіт з'явиться **тільки після успішної реальної відповіді**.

Ключ не надсилайте в чат, не зберігайте в HTML або JavaScript, не публікуйте у GitHub.

## Квоти та достовірність

- Модель за замовчуванням: gemini-2.5-flash; має бути доступна у вашому акаунті.
- Не більше двох відео на двогодинний запуск; консервативний резерв на сумарно 6 годин відео за UTC-добу (документований ліміт безплатного рівня — 8 годин).
- Для відео з невідомою тривалістю система резервує додатковий час; невдалі відео не приписуються успішним.
- Функція YouTube URL у Gemini API перебуває у preview; квоти й ціни можуть змінюватися. Звертайте увагу на ліміти та можливу оплату викликів моделі.
- За замовчуванням Gemini семплює приблизно 1 кадр на секунду. Можна пропустити миттєві угоди, деталі графіка, а часові мітки можуть бути неточними.
- Результати AI не підтверджують ринкові котирування, справжність балансу чи виграшну статистику трейдерів і не є рекомендаціями робити ставки.

Офіційна документація: https://ai.google.dev/gemini-api/docs/video-understanding
