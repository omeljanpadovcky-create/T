⚠️ Локальний режим не запускається з GitHub Pages.

Потрібно запустити Ollama через PowerShell і відкрити локальну адресу цього ж додатка.

Відкрити локальну Мишку ↗

Локальний режим працює на сторінці http://127.0.0.1:18765/myshka-app.html. Публічна GitHub Pages не запускає локальну Ollama. Без дозволу автоматичного передавання фото в хмару не буде.

☁️ Хмарний JEV — аналіз без увімкненого ПК

Це окреме підключення, n8n тут не потрібен. GitHub Pages не запускає AI самостійно. На своєму Vercel-сервері перевір APINEX_API_KEY та створи окремий JEV_ACCESS_TOKEN (мінімум 24 символи). Після розгортання введи нижче URL сервера й лише код доступу JEV. API-ключ APInex сюди не вставляй. Відкрити твій проєкт Vercel «t» ↗

Якщо APInex повертає HTTP 402: сервер авторизований, але обробка фото обмежена квотою, балансом або доступом до моделі. Можна використати прямий Gemini API без n8n: створи власний ключ у Google AI Studio ↗, додай його в Vercel → Environment Variables ↗ як GEMINI_API_KEY (Production) і виконай Redeploy. Коли він заданий, аналіз фото використовує прямий Gemini gemini-2.5-flash-lite замість APInex. Google має безкоштовний рівень із квотами; обов'язково перевір тариф свого проєкту. Сам ключ сюди або в чат не вставляй.

Без AI-сервера теж можна: переглядати 10 трейдерів Bybit, імпортувати їхні угоди та бачити розраховані показники. Для аналізу скріншота можеш надіслати фото прямо в наш чат.
